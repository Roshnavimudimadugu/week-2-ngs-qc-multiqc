# MultiQC Raw Data

This folder contains the raw data and summary files generated by MultiQC during the quality control analysis.

MultiQC aggregates results from FastQC analyses and produces summary information for multiple sequencing datasets.

The raw data files contain the underlying quality control information used to generate the MultiQC report.

## Analysis Tool

**MultiQC**

## Platform

**Galaxy**

## Purpose

The MultiQC raw data files provide the underlying summary data used to generate the MultiQC quality control report and compare the sequencing datasets.
