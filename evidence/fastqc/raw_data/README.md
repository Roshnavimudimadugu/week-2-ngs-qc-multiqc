# FastQC Raw Data

This folder contains the raw output files generated by FastQC during the quality control analysis.

The FastQC analysis was performed using the Galaxy Training Network Quality Control tutorial.

The raw data files contain detailed quality control metrics used by FastQC to assess sequencing read quality, including:

- Basic Statistics
- Per Base Sequence Quality
- Per Sequence Quality Scores
- Per Base Sequence Content
- Per Sequence GC Content
- Sequence Duplication Levels
- Overrepresented Sequences
- Adapter Content

These raw FastQC outputs provide the underlying data used to generate the FastQC quality control reports and plots.

## Analysis Tool

**FastQC**

## Platform

**Galaxy**

## Tutorial Followed

Galaxy Training Network – Quality Control tutorial.
